# Adaptation Noctys Watches

Version française du pack, réglée pour Noctys Watches et branchée sur Jarvis.

- `voice.md` : profil de voix de la marque (hypothèses marquées, trous `{{...}}` à combler).
- `jarvis-instagram/SKILL.md` : les 13 skills fusionnées en un pôle Instagram pour
  Jarvis, en français, avec les 26 formules de hook adaptées, l'humaniseur FR et les
  garde-fous marques (aucune marque ni modèle tiers dans le contenu).

Outils Python utilisables tels quels en français : `skills/ig-reel/beats.py --wpm 150`
et `skills/ig-caption/caption.py`. Les autres sont calibrés sur l'anglais.
